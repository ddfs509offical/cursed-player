# Cursed player

Музыкальный плеер для Windows и Android: локальная библиотека, поиск и
воспроизведение через SoundCloud, тексты песен, синхронизация аккаунта между
устройствами и офлайн-копии прослушанного.

**Сайт:** https://cursedplayer.netlify.app
**Скачать:** релизы этого репозитория (Windows и Android).

## Что умеет

- **Локальная библиотека.** Папки сканируются целиком, теги и длительность
  читаются из файлов, обложки подхватываются оттуда же.
- **SoundCloud.** Поиск, тренды по жанрам и регионам, «волна» из похожих
  треков. Ключ веб-клиента обновляется сам, когда старый перестаёт работать.
- **Тексты песен.** Синхронные `.lrc`, если они есть; офсет подстраивается
  под слух.
- **Офлайн.** Прослушанные треки сами сохраняются на диск, локальные играют
  как есть.
- **Аккаунт.** Лайки, история, плейлисты и настройки синхронизируются между
  компьютером и телефоном. Вход по ключу приглашения.
- **Оформление.** Чёрно-белая гамма: белый акцент, серые поверхности, без
  градиентов. Оболочка перестраивается по ширине окна: на телефоне — нижняя
  навигация и мини-плеер, на компьютере — панель разделов и транспорт.

## Установка

### Windows

1. Скачай `Cursed player setup.exe` из раздела релизов.
2. Запусти: установщик сам поставит WebView2, если его нет в системе.
3. Приложение появится на рабочем столе как `Cursed player.exe`.

Есть портативная версия `Cursed player (portable).zip` — распаковать и
запустить, ничего не устанавливая.

### Android

1. Скачай `Cursed Player.apk` из релизов.
2. Разреши установку из неизвестных источников для этого файла.
3. Нужен Android 7.0 и новее.

## Сборка из исходников

```bash
npm install                 # зависимости фронтенда
npm run desktop             # настольная сборка, exe на рабочем столе
npm run release             # полный выпуск: версия, установщик, latest.json
```

Для разработки:

```bash
npm run dev                 # фронтенд на http://localhost:1420
npm run tauri dev           # приложение с горячей перезагрузкой
```

### Android

Нужны Android SDK, NDK и Rust-таргет `aarch64-linux-android`:

```bash
npm run tauri android build -- --apk --target aarch64
```

Готовый APK появится в `src-tauri/gen/android/app/build/outputs/apk/arm64/release/`.

## Технологии

| Слой | Что используется |
|---|---|
| Оболочка | Tauri v2 (Rust) |
| Интерфейс | React 18, TypeScript, Vite, Tailwind CSS, framer-motion, zustand |
| Хранилище | SQLite для профилей, JSON в папке данных приложения |
| Аккаунт | Supabase: авторизация, синхронизация, приглашения |
| Android | Kotlin-плагин для выбора файлов, проверка обновлений внутри APK |

## Структура

```
src/            интерфейс: страницы, компоненты, состояние
  mobile/       мобильная оболочка
src-tauri/src/  ядро: плеер, сервисы, хранение, синхронизация
src-tauri/gen/  проекты для Android
supabase/       SQL для приглашений и обновлений
site/           сайт проекта
```

## Обновления

**Windows.** Приложение проверяет `latest.json` в хранилище и предлагает
установить новую сборку.

**Android.** Внутри APK своя проверка: она читает `android.json`, сравнивает
номер сборки и предлагает скачать APK. Установку подтверждает система.

Выпуск новой версии:

```bash
npm run release             # поднимает номер сборки, собирает и готовит файлы
```

## Лицензия

Исходный код открыт для чтения и личного использования. Музыка, которую играет
приложение, принадлежит её авторам: плеер ничего не раздаёт и не обходит
ограничения сервисов.
