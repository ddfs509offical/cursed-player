## 2. Правила работы (важнее любой фичи)

1. **Экономия.** По умолчанию задачу делает основной агент; подрядчик — только на крупное и
   независимое; **не больше одного подрядчика за раз** (параллельные затирают файлы).
   Не читать файлы целиком — искать по символу, читать окнами, не перечитывать уже правленное.
   Точечные правки вместо перезаписи. Вывод команд фильтровать. Не проверять одно и то же дважды.
   Сборка/тесты/запуск бесплатны — экономить на них не надо. В конце партии — строка расхода.
2. **Честность.** Не писать «исправлено», пока нет замера/теста. Причину искать диагностикой,
   а не догадкой; в отчёте — «до/после». Если не воспроизвёл — так и говорить.
3. **Безопасность.** Никогда не вшивать и не копировать чужие токены/ключи. `service_role`/`sb_secret`
   не используются и не запрашиваются. Только публичные ключи, которые по дизайну лежат в клиенте.
4. **Никаких внешних прокси-сервисов** (в т.ч. публичные прокси-листы, `proxy.dotify.fun` и подобное):
   это чужие серверы, которые видят трафик и ломаются без предупреждения.
5. **Пользовательские данные** (лайки, офлайн, тексты, профили) не терять; удаления — «надгробиями»
   с синхронизацией, а не мгновенным стиранием.
6. Общение — по-русски, без канцелярита, с прямым мнением и без «раба».

## 4. Что уже сделано (сводка)

**Воспроизведение:** SoundCloud-поиск с фильтром мусора и ранжированием; HLS и progressive; офлайн-копии
имеют приоритет над сетью; кэш ссылок 10 минут; предзагрузка следующего трека; нормализация громкости
не сделана (в очереди).

**Волна (Wave):** включается кнопкой-пилюлей в плеере; порция 15 = ~60% related + ~25% треки связанных
артистов + ~15% жанр; вставляется **сразу после текущего**; удаляется при выключении (кроме играющего);
не работает при shuffle/repeat (с тостом); кэш 10 минут, один запрос за раз, 3 неудачи → выключение;
**дедуп по `songKey`** (название+исполнитель+окно длительности 2с, маркеры версий сохраняются).

**Офлайн:** сохранение трека, текста или обоих (окно выбора «Что сохранить?», галочка «запомнить»
по умолчанию СНЯТА); HLS собирается нативно (fMP4/ADTS/TS); вкладка «Скачанные»; «держать офлайн»;
очистка по возрасту; «Показать все» при >100 строк. **Плейлист офлайн целиком:** кнопка в шапке
плейлиста и в меню карточки, последовательное докачивание недостающих треков с прогрессом
(`services/playlistOffline.ts`), уже сохранённые и локальные пропускаются, статус «скачано/частично»
считается по офлайн-реестру, а не хранится флагом.

**Тексты:** LRCLIB → Netease → Genius (страницы genius.com, без ключей и без синхронизации,
живой smoke-тест `cargo test genius_live -- --ignored`) → lyrics.ovh; строгое сопоставление (производные/коллажи → «текст от оригинала»);
смещение ±0.5с и тумблер «для всех треков»; клик по строке → переход к моменту; файлы `.lrc` на диске;
единый ключ (`lyricsKey.ts`) — в «Скачанных» текст больше не ищется заново (0 сетевых вызовов);
опция «пропускать тишину в конце трека» (только для локальных файлов, порог −50 dBFS, 32 теста).

**Лайки и библиотека:** один канонический ключ для всех списков (миграция дублей); «Все треки» =
локальные + офлайн + лайки + очередь (дедуп); поиск по названию/исполнителю/альбому, сортировка
(название/исполнитель/длительность/дата), группировка по артистам/альбомам, липкие заголовки,
выбор запоминается.

**Плейлисты:** создание/переименование/удаление, обложка из треков, drag&drop порядка, «＋ в плейлист»
из библиотеки, синхронизация в облако.

  (`owner` / `user` / `null`). По этой роли, а не по нику локального профиля, прячутся «Тест» в меню,
  «О приложении → В разработке» и блок «Дополнительно (для разработчика)» — раньше достаточно было
  назвать профиль `developer`.
- **Админ-панель** (`src/pages/Admin.tsx`, открывается из «Аккаунт → Владелец → Админ-панель»):
  сводка (аккаунты, активные коды, регистрации по кодам, устройства), тумблер «регистрация для всех»,
  список людей с почтой и числом устройств, список привязок и коды приглашений с журналом.
  Все `admin_*` функции на сервере начинаются с проверки `is_app_owner()` и отвечают `not_allowed`

**Открытая регистрация и автообновление (30.10):**
- **Флаг регистрации в клиенте.** `app_registration_state()` (RPC, доступен anon) отдаёт
  `{open}`; экран входа спрашивает его при старте и, если регистрация открыта владельцем,
  сразу показывает форму создания аккаунта — ключ больше не требуется. Раньше флаг жил только
  в базе, и приложение просило код даже при `open = true`.
- **Автообновление.** `npm run release` поднимает `APP_BUILD` (`src/lib/app.ts`), собирает
  установщик, кладёт файлы на рабочий стол и пишет `dist-update/latest.json`. Владелец
  загружает `latest.json` и установщик в Storage → бакет `updates` (публичный на чтение).
  Приложение раз в 6 часов читает `latest.json` (`src-tauri/src/update.rs`), сравнивает номер
  сборки и предлагает обновление; по кнопке `update_download` скачивает установщик в temp,
  `update_launch` открывает его — дальше работает NSIS. Ручная проверка — «О приложении →
  Приложение → Обновления».
- **SQL:** `supabase/migrations/20261030_registration_updates.sql` (RPC + бакет), в сборке
  `npm run sql` он же лежит в `supabase/REGISTRATION-UPDATES.sql`.

**Текст из Genius с таймингом (30.10):** Genius не отдаёт синхронный текст, поэтому раньше
его строки шли «мёртвым» списком без подсветки. Теперь `estimate_lrc` раскладывает строки по
длительности трека (вес по числу символов, 6% на вступление, 8% на концовку), `with_estimated_timing`
подставляет это как LRC и ставит `estimated: true`; панель пишет «тайминг примерный», кнопки ±
сдвигают сетку. Заодно почищена страница: Genius кладёт в контейнер текста шапку («167 Contributors»)
и переводы с `data-exclude-from-selection` — теперь такие блоки, кнопки и svg вырезаются
(`genius_strip_service_blocks`). Ранг такого текста 15 — выше обычного, но ниже любого настоящего LRC.
Проверки: `cargo test lyrics::` (100 тестов) и живые `genius_live_search_and_page`,
`genius_live_estimated_timing`.

**Стабильность:** защитные экраны ошибок (ErrorBoundary) вместо белого экрана; все анимации входа
имеют **видимое базовое состояние** (сбой кадров больше не делает интерфейс невидимым); слои снимаются
по таймеру (`useExitGuard`), клики не перехватываются призраками; один экземпляр приложения; без окон консоли.

**Пасхалка:** есть личная скрытая (слово → звёздочка → 3 клика → созвездие → окно с фразами; второй вход —
акцент `41 47 92`). Строки обфусцированы (хеш слова, XOR+base64 фразы, упакованный цвет, непрозрачные ключи
localStorage). **Сам путь в этом файле не записан намеренно** — иначе обфускация теряет смысл; владелец знает.
Сброс: удержание звезды 1.2с, либо «О приложении → В разработке → Скрытый слой».

## 5. Известные ограничения и риски

- **Spotify:** звук недоступен легально без Premium+SDK; `sp_dc` (cookie-сессия) использовать **нельзя**.
  Максимум — каталог/поиск по официальному API с ключом приложения (ключ извлекаем из клиента — риск отзыва).
- **Яндекс Музыка:** публичного API нет; поддержки нет и не планируется.
- **Dotify** (стороннее приложение) изучено и удалено: это Tauri+WebView2, метаданные Spotify + звук
  из SoundCloud **через свой сервер** `proxy.dotify.fun`, с антиотладкой, вшитыми секретами и отпечатком
  устройства. Ничего не копировали.
- **`hosts`** на машине содержит перенаправления доменов Spotify и OpenAI на сторонние IP — владелец
  решил не трогать; причастность Dotify не подтверждена (правки были раньше установки).
- **Акцент из обложки** — эвристика (canvas 24×24); при неудаче тихо откатывается к теме.
- **`songKey`** — эвристика: две разные песни с одинаковым названием/исполнителем и длиной ±2с схлопнутся.
- **Офлайн-тексты:** файл, лежавший под «сырым» ключом, найдётся только когда реестр офлайна прочитан.
- **Wave** не работает при shuffle/repeat (осознанно, с тостом).
- Проверки дизайна частично статические (скриншоты/замеры), не всегда живой клик — см. раздел «Проверки».
- Железо пользователя: 15.7 ГБ ОЗУ; при 22 днях аптайма коммит доходил до 56 ГБ и система подвисала —
  рекомендованы перезагрузки и «не запускать сборки при открытых Steam/Discord».
